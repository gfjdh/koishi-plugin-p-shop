# 素材与排版

- `satori-scene.png`：根据本次确认的觉背包设计，使用 imagegen 内置编辑模式清除文字、行列与图标，保留相同人物、姿势、品红斜面和灰阶背景。作为商店／背包共用底图。
- `satori-fumo.png`：使用 imagegen 内置模式生成的独立透明 fumo 图标，与确认的觉造型保持一致，包含第三只眼。
- `icons/*.svg`：按截图物品类型重新绘制的矢量图标，源码见 `scripts/create-icons.cjs`。颜色限定黑、白、灰及品红。
- `fonts/`：Noto Sans SC 的 900／500 固定字重实例，分别用于标题清单和正文，保留完整中文字库以支持后续填写描述。许可见同目录 `OFL.txt`。

底图生成约束：保持确认稿中觉的银灰短发、黑发箍、品红眼睛、圆领袖口、左胸第三只眼、点额头动作、硬边赛璐璐阴影和人物位置；清除所有 UI 文字、图标、价格、选中条和白色说明面板；左侧留空灰阶几何区域；全图仅黑白灰与品红。

fumo 生成约束：独立坐姿毛绒玩偶、透明背景、银灰短发、品红眼睛、左胸开放的第三只眼及连线、简洁圆领灰白上衣、无大领结；仅黑白灰与品红。

动态元素均由 `src/paint.js` 逐次绘制。修改道具名、描述、价格、库存或获取途径，无需修改人物素材。
